# VectorCraft tarifi

Türkçe rozet, pathfinder, degrade ve outline metin üretir. `vectorcraft-cli run --commands vectorcraft-tarif.jsonl` komutunu çalışma klasöründe çalıştırın.

Beklenti: 3840×2160 RGBA PNG, SVG, tek sayfa PDF ve `.vectorcraft` proje. `dither:true` SVG/PDF degrade öğesini rasterlaştırır; saf vektör için `false` yapın.
