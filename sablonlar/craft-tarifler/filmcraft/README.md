# FilmCraft uçtan uca tarif

Video, iki alfa MOV ve final WAV'ı 4K25 sekansa yerleştirir. `hat.jsonl` içindeki `$GIRDI` ve `$CIKTI` yer tutucularını geçerli çalışma yollarına çevirip `filmcraft-cli run hat.jsonl` çalıştırın. CLI JSONL içinde kabuk değişkeni açmaz.

Beklenti: 3840×2160, 25 fps, 48 kHz proje; V1 kaynak ses kapalı, V2/V3 alfa katmanları ve A1 miks. `render-frame` ile kompoziti gözle denetleyin.
