# Konuşma temizliği

`./temizle.sh girdi.wav cikti.wav` ffmpeg ön temizliği, SoundCraft gate/EQ/de-esser/compressor ve −14 LUFS loudnorm uygular. Ölçülen örnekte gürültü tabanı −40,3 → −60,4 dB, konuşma −23,5 → −14,1 LUFS, true peak −1,4 dB; yaklaşık 29 dB gürültüye göre iyileşme. Çıktıyı dinleyin; gate ünsüz sonlarını kesebilir.
